# SkillSpring Design System

## Color styles
- Brand / Purple: `#7058E8`
- Brand / Purple Dark: `#5942CC`
- Text / Primary: `#20213A`
- Text / Secondary: `#6F7188`
- Surface / White: `#FFFFFF`
- Surface / Lavender: `#F3F0FF`
- Accent / Mint: `#DFF8ED`
- Accent / Peach: `#FFEADB`
- Border / Light: `#EAE9F2`

## Typography styles
Use Manrope for headings and DM Sans for body text.
- Heading / H1: Manrope ExtraBold, 64 px desktop / 42 px mobile, line height 1.12
- Heading / H2: Manrope Bold, 42 px desktop / 31 px mobile, line height 1.2
- Heading / H3: Manrope Bold, 19 px
- Body / Regular: DM Sans Regular, 16 px desktop / 12 px mobile
- Body / Small: DM Sans Regular, 12 px
- Label / Eyebrow: DM Sans Bold, 10 px, letter spacing 1.5 px
- Button / Label: DM Sans Bold, 14 px

## Components to create in Figma
### 1. Button / Primary
- Horizontal Auto Layout
- Padding: 15 px vertical, 21 px horizontal
- Gap: 18 px
- Fill: Brand / Purple
- Radius: 12 px
- White bold label and arrow

### 2. Feature / Card
- Vertical Auto Layout
- Padding: 27 px
- Gap: 12 px
- Fill: white, 1 px Border / Light, radius 20 px
- Contains icon tile, number label, heading, description, and text link
- Make 3 instances and update text for each feature

### 3. Navigation / Link
- Horizontal Auto Layout
- Padding: 8 px
- DM Sans Semibold, 14 px
- Reuse for each navigation item

## Auto Layout
- Header: horizontal, space-between, center aligned, 84 px height
- Hero: horizontal groups on desktop with 44 px gap; vertical stack on mobile
- Feature grid: horizontal with three equal-width cards and 20 px gap; stack vertically on mobile
- Content groups: vertical Auto Layout, consistent 16/24/40 px spacing
- Footer: horizontal on desktop, vertical on mobile
- Use Hug contents for buttons and text; Fill container for flexible cards

## Target audience
College students, beginners, and early-career learners who want practical skills and portfolio projects.
